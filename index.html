Pertanyaan umum

Apakah hasilnya langsung berupa PDF?

Ya. Tombol Unduh PDF membuat satu file PDF A4 langsung di browser, tanpa dialog cetak dan tanpa server tambahan.

Bagaimana tata letak untuk empat label?

Empat label disusun dua kolom dan dua baris pada bagian atas halaman. Untuk dua label, keduanya disusun berdampingan dalam satu baris.

Apakah PDF benar-benar borderless?

File PDF tidak memiliki margin halaman. Jarak label dari tepi dapat dibuat 1,5 mm. Kemampuan mencetak sampai tepi fisik kertas tetap bergantung pada printer.
